# AgriFeed POS — GitHub Pages

Upload every file in this folder to the repository root and publish from `main` / root.

Open https://yatzy200011-spec.github.io/ARBambang/ in Chrome on Android while online, wait for loading to finish, then choose **Install app**.

If the previous broken app entry exists, uninstall it first. Clear site data only after backing up local POS records, because clearing site data can erase them. Reload the published site online, then install again.

Open the published site online once to cache the app shell for offline use. Data stays on the device and does not sync automatically.
